# Hospital Management Dashboard -- Power BI

## Project Overview

The **Hospital Management Dashboard** is a Power BI project designed to
present hospital-related data in an interactive and easy-to-understand
format. It helps users explore healthcare data, monitor key indicators,
and identify useful patterns for reporting and decision-making.

## Objectives

-   Present hospital data through interactive Power BI visuals.
-   Make key information easier to monitor and compare.
-   Support data-driven reporting with filters and visual summaries.
-   Practice data analytics, visualization, and dashboard design skills.

## Tools Used

-   **Microsoft Power BI Desktop** -- report building and visualization
-   **Power Query** -- data preparation and transformation, where
    applicable
-   **DAX** -- measures and calculations, where applicable

## Dashboard Features

The report is provided as a Power BI `.pbix` file. The exact metrics and
visuals depend on the fields and pages included in the report. Typical
hospital-reporting views may include: - Summary cards for important
healthcare or operational indicators - Charts for comparing categories
and trends - Tables or matrices for detailed records - Slicers and
filters for interactive exploration

> **Note:** Update this section with the exact KPIs, chart names, and
> report pages after reviewing the dashboard in Power BI.

## How to Open the Project

1.  Download or clone this repository.
2.  Install **Power BI Desktop** if it is not already installed.
3.  Open `Hospital project.pbix` in Power BI Desktop.
4.  If Power BI prompts you to configure data sources or credentials,
    follow the prompts.
5.  Refresh the data if the source files or database are available and
    connected.
6.  Use the report pages, slicers, and filters to explore the dashboard.
